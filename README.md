# 신동민 포트폴리오

로보틱스·임베디드 시스템 프로젝트에서 담당한 역할과 구현 내용을 소개합니다.

| 순서 | 프로젝트 | 담당 |
| --- | --- | --- |
| 01 | ROS 2 스마트팜 · 진행 중 | 예찰 로봇 주행, 작업 정보 생성, FSM·관제 연동 |
| 02 | POCO 온디바이스 AI | 짐벌, 프론트엔드, 멀티프로세싱, 형상 관리·코드 병합 |
| 03 | STM32 KICK-CAN | Controller 하드웨어·펌웨어 |
| 04 | PLC 자동 적재·출고 | HMI 화면 구성·배출 제어 |

- 반응형 정적 웹사이트이며 별도 빌드가 필요하지 않습니다.
- `portfolio.pdf`는 프로젝트별 1-2장으로 구성한 7장 제출용 PDF입니다.
- GitHub Pages는 `main` 브랜치의 루트 디렉터리에서 배포합니다.
- 내용과 스타일은 `index.html`, `style.css`에서 수정할 수 있습니다.
- 사진은 사용자 제공 자료 및 해당 프로젝트 저장소의 실제 제작 자료입니다.
