# 신동민 포트폴리오

[포트폴리오 보기](https://dongmins11.github.io/portfolio/)

임베디드 시스템과 로보틱스 개발 경험을 소개하는 정적 웹사이트입니다.

- 소개: 프로필 사진, 개발 방향, 기술 스택
- 진행 중: 스마트팜 예찰 로봇의 주행·작업 흐름 설계
- 완료 프로젝트: POCO → KICK-CAN → PLC Automated Warehouse
- 프로젝트별 상세: 개요, 기능 시연, 설계, 구현 결과, 문제 해결, 회고

GitHub Pages는 `main` 브랜치 루트에서 배포합니다. 별도 빌드는 필요하지 않습니다.

`index.html`은 메인 화면이며, `poco.html`, `kickcan.html`, `plc.html`은 상세 페이지입니다.
`style.css`, `redesign.css`는 디자인, `app.js`는 GIF 전환과 영상 재생을 담당합니다.

사진과 시연 자료는 본인 제공 자료와 프로젝트 자료를 사용했습니다. 팀 성과와 개인 담당 범위를 구분합니다.
