01 / AI & EMBEDDED4인 팀 · 개발 완료

POCO

AI 자세 코칭 모니터암

프로젝트 개요

카메라로 자세를 분석하고 교정 피드백·일일 리포트를 제공하며, 정상 자세에서는 모니터 위치와 수평을 조절하는 AI 자세 코칭 시스템입니다.

개발 배경과 목표

자세 안내만으로 바뀌지 않는 작업 환경을 함께 개선하고자 했습니다. 잘못된 자세는 교정을 유도하고, 정상 자세를 기준으로 모니터가 움직이도록 자세 판단과 장치 제어를 연결했습니다.

담당 역할

PyQt 화면·리포트, 실행 구조 통합, IMU·PID 모니터암 수평 보정

  • Python
  • PyQt5
  • Streamlit
  • Raspberry Pi 5
  • IMU / PID
프로젝트 자세히 보기 01

트러블슈팅

문제
자세 분석·장치 제어 중에도 사용자 입력과 화면 갱신이 이어져야 했습니다.
원인
시간이 걸리는 분석·제어 작업을 화면 처리와 같은 실행 흐름에 두면 UI가 작업 완료를 기다릴 수 있었습니다.
고민한 점
화면 응답과 분석 처리량을 나누고, 작업 결과만 안전하게 화면에 전달하는 경계를 설계했습니다.
해결 방식
카메라는 QThread, 분석·장치 제어는 별도 프로세스로 분리했습니다. 영상은 Shared Memory, 명령·상태는 Queue로 전달하고 UI는 결과 신호로 갱신했습니다.
02 / EMBEDDED CONTROL4인 팀 · 개발 완료

KICK-CAN

STM32 분산 임베디드 RC카

프로젝트 개요

카드 인증을 거친 사용자가 무선 조종기로 RC카를 운전하고, 차량 내부의 구동·센서·화면 장치가 CAN 통신으로 정보를 주고받는 시스템입니다.

개발 배경과 목표

실제 차량 전장의 역할 분담과 통신 구조를 작은 RC카에 구현하고자 했습니다. 조종·구동·환경 감지·상태 표시를 별도 장치로 나누고, 명령과 상태 정보를 연결하는 것을 목표로 했습니다.

담당 역할

무선 조종기 하드웨어·펌웨어, RFID 인증, 입력 처리·명령 송신

  • C
  • STM32F411
  • FreeRTOS
  • Bluetooth
  • CAN
프로젝트 자세히 보기 02

트러블슈팅

문제
차량에서 수신한 제어 명령을 정상적으로 해석하지 못했습니다.
원인
수신 프레임 경계가 밀리고 불필요한 데이터가 섞였으며, 처리 중인 버퍼를 DMA가 덮어쓰는 문제가 있었습니다.
고민한 점
명령 규약뿐 아니라 송신·수신의 처리 시점과 버퍼를 언제 사용하고 반환할지도 함께 맞춰야 했습니다.
해결 방식
조종기에 시작·종료 바이트와 XOR 체크섬, UART Mutex 송신을 구현했습니다. 팀 통합에서는 차량 측 DMA를 Normal 방식으로 바꾸고 수신·처리를 분리했습니다.
03 / INDUSTRIAL AUTOMATION팀 프로젝트 · 개발 완료

PLC Automated Warehouse

소재 분류·적재·배출 자동화 시스템

프로젝트 개요

금속·비금속 소재를 구분해 창고에 적재하고, 터치 조작 화면에서 저장 상태를 확인하며 필요한 소재를 꺼내는 PLC 기반 자동화 시스템입니다.

개발 배경과 목표

소재 공급부터 분류·보관·출고까지 하나의 공정으로 연결하는 것이 목표였습니다. 소재 종류와 저장 위치를 관리하고, 자동 배출뿐 아니라 지정 위치의 소재 배출과 창고 전체 비우기를 지원하도록 구성했습니다.

담당 역할

선택·전체 배출 순서, 작업 전환, 중복 실행 방지

  • PLC
  • Ladder Logic
  • GX Works2
  • GT Designer3
  • HMI

트러블슈팅

문제
선택 배출 도중 전체 배출을 요청하면 장비의 동작 순서가 꼬였습니다.
원인
현재 작업이 끝나기 전에 다른 배출 모드가 동시에 개입했습니다.
고민한 점
정상 동작 순서 외에도 작업 도중 들어오는 추가 명령과 모드 전환 조건을 설계해야 했습니다.
해결 방식
작업 진행 상태를 확인하는 인터락을 추가했습니다. 실행 중인 배출 모드를 유지하고 다른 배출 명령의 개입을 차단했습니다.
